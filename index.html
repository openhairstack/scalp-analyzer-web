What this is (and isn't)

Is: a research demo of an open follicular-unit detector, plus a transparent graft-planning sandbox. Every number printed below is computed by code you can read in this repo.

Is not: a medical device, diagnostic, or surgical plan. Not FDA/CE cleared. The pattern readout is a heuristic, and the plan simulation allocates imaginary grafts using published planning assumptions. If you are losing hair, see a dermatologist.

v0.1 baseline trained on ~688 public CC-BY images. It will miss things. Failure reports are the most valuable thing you can contribute: file one.
